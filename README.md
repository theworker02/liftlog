# liftlog

Lift color log values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/liftlog/

## Install / run

```bash
git clone https://github.com/theworker02/liftlog.git
cd liftlog
node src/cli.js
node --test
```
